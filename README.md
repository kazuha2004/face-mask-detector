# 🎯 LumiFace - AI-Based Face Recognition Attendance System

An AI-powered Face Recognition Attendance System developed using **Python**, **OpenCV**, **LBPH**, **Haar Cascade**, **Tkinter**, and **MySQL** to automate attendance management with real-time facial recognition.

---

## 📌 Project Overview

LumiFace is a smart attendance management system that eliminates manual attendance by automatically recognizing faces using Computer Vision techniques.

The application provides:

- Real-time face recognition
- Automatic attendance marking
- Student management
- Attendance reports
- Analytics dashboard
- Chatbot assistance
- Secure database integration

This project was also published as an **Indian Patent Application**.

---

## 🚀 Features

✅ Face Recognition using OpenCV

✅ Local Binary Pattern Histogram (LBPH)

✅ Student Registration

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/FACE_RECOGNITION_ATTENDANCE_SYSTEM.git
```

### Move into Project Folder

```bash
cd FACE_RECOGNITION_ATTENDANCE_SYSTEM
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run

```bash
python Developer.py
```
